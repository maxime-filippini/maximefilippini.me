import VarExplorer from "./VarExplorer.svelte";

This draft shows the pattern for interactive posts: write the component next to the post,
import it at the top of the file, then drop it in the text with a `client:` directive so
Astro ships its JavaScript.

<VarExplorer client:visible />

`client:visible` loads the component's code only when it scrolls into view, so the rest of the
page stays as plain HTML.

Inline maths works too: the parametric VaR is $\mathrm{VaR}_\alpha = -\mu + \sigma\, z_{\alpha}$, and

$$
\mathrm{ES}_\alpha = -\mathbb{E}\left[X \mid X \le -\mathrm{VaR}_\alpha\right].
$$
